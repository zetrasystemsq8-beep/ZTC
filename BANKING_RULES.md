# ZTC Banking Rules

## Purpose

ZTC is the official banking platform of Zetra.

Every user has one secure bank account linked to one Zetra ID.

---

# Account

Each account has:

- Account Number
- Username
- Full Name
- Wallet Balance
- Account Status
- KYC Status
- Date Created

Account numbers never change.

---

# Wallet

Wallet Balance cannot go below ₦0.

Every transaction updates the balance immediately.

Every transaction has a unique Transaction ID.

---

# Transaction Types

- Deposit
- Withdrawal
- Transfer
- Airtime
- Data
- Bill Payment
- Cashback
- Reward
- Refund

---

# Transfers

Users can send money:

- To another ZTC user
- To Nigerian banks (future)

Every transfer records:

- Sender
- Receiver
- Amount
- Time
- Status
- Transaction ID

---

# Rewards

Coins are separate from money.

Coins can come from:

- NAI Challenges
- Daily Login
- Achievements
- Referrals

Coins may later be converted to ZTC balance when approved by the backend.

---

# Security

Every transfer requires:

- PIN

Large transfers may also require:

- Fingerprint
- Face ID
- OTP

---

# Transaction Status

- Pending
- Successful
- Failed
- Reversed

---

# Notifications

Notify users instantly for:

- Deposits
- Withdrawals
- Transfers
- Security alerts

---

# Limits

Daily transfer limits depend on KYC level.

Higher verification unlocks higher limits.
